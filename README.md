# Базовые правила определения доступного лимита кредитной карты

## Глоссарий
Максимальный лимит - предельная сумма для данного продукта.
Одобренный лимит - сумма, которую банк готов предоставить заемщику.
Доступный лимит - одобренный лимит за вычетом кредитной экспозиции, т.е. выданных банком средств в виде займов и лимитов по кредитным картам.
Резерв лимита - сумма одобренных, но не выданных заявок.
Сумма заявки - сумма, запрашиваемая клиентом для одобрения в рамках одного кредитного продукта.

## Факторы, влияющие размер доступного лимита:
- Максимальный лимит продукта
- Одобренный лимит клиента
- Сумма выданных кредитов
- Резерв лимита

## Характеристики доступного лимита
- Не может быть отрицательным
- Не может превышать одобренный лимит
- Не может превышать максимальный лимит продукта

## Общая формула доступного лимита
Доступный лимит = Одобренный лимит - Сумма выданных кредитов - Резерв лимита
