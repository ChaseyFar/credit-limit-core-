# Базовые правила определения доступного лимита кредитной карты

## Глоссарий
Максимальный лимит - предельная сумма для данного продукта.
Одобренный лимит - сумма, которую банк готов предоставить заемщику.
Доступный лимит - одобренный лимит за вычетом кредитной экспозиции, т.е. выданных банком средств в виде займов и лимитов по кредитным картам.
Резерв лимита - сумма одобренных, но не выданных заявок.
Сумма заявки - сумма, запрашиваемая клиентом для одобрения в рамках одного кредитного продукта.

## Факторы, влияющие размер доступного лимита:
- Максимальный лимит продукта
- Одобренный лимит клиента
- Сумма выданных кредитов
- Резерв лимита

## Характеристики доступного лимита
- Не может быть отрицательным
- Не может превышать одобренный лимит
- Не может превышать максимальный лимит продукта

## Общая формула доступного лимита
Доступный лимит = Одобренный лимит - Сумма выданных кредитов - Резерв лимита

# Сущности в составе публичного пакета

## evaluate_application 
Описание: функция для принятия решения по одобрению кредитного лимита
Входные параметры:
- client_approved_limit - одобренный лимит клиента 
- client_outstanding_debt - сумма выданных кредитов клиента 
- client_reserved_amount - резерв лимита по всем одобренным, но не выданным, заявкам клиента
- product_max_limit - максимальный лимит продукта 
- requested_amount - сумма заявки 
Структура ответа: 
- при невалидном значении одного из входных параметров возвращает ValidationError 
- при валидных входных данных формирует бизнес решение и возвращает ApplicationDecision

## ValidationError 
Описание: dataclass, доменный ответ функции evaluate_application в случае ошибки валидации хотя бы одного входного параметра функции (правила валидации см. в /docs/domain-rules.md)
Параметры:
- code - константа "invalid_amount"
- field - наименование входного параметра, не прошедшего валидацию

## ApplicationDecision 
Описание: dataclass, доменный ответ функции evaluate_application в случае принятия бизнес решения (отказа/акцепта) по заявке
Параметры:
- decision - код решения ("approved"/"rejected")
- reason_code - причина принятия решения
    - None - в случае "approved"
    - "request_exceeds_product_max_limit" - отказ по причине превышения суммы заявки над лимитом продукта
    - "request_exceeds_allowed_amount" - отказ по причине превышения суммы заявки над доступным лимитом заявки
- allowed_amount - максимально допустимая сумма для текущей заявки:
    - максимальный лимит продукта в случае превышения заявкой лимита продукта
    - результат расчета доступной суммы
